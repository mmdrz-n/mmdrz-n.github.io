Why learn this at all?

Calculators exist. There's even one on my homepage. But in an interview, an exam, or a 2 AM outage with someone reading a config out loud, the person who can say "that's in the .128 network, broadcast .191" without opening anything is the person everyone trusts.

The good news: you only need to memorise one row of eight numbers.

The only table you need

Inside any octet, the mask can only take eight values. Each one has a block size: the step between networks.

Shortcut

Block size = 256 − mask octet. You never have to memorise the third column, only the masks.

The method in four steps

  1. Find the interesting octet. /1–/8 → first octet, /9–/16 → second, /17–/24 → third, /25–/32 → fourth.
  2. Get the block size from the table (prefix minus 0, 8, 16 or 24 gives you the "bits in the octet").
  3. Network: take the IP's value in that octet, round down to a multiple of the block size. Octets after it become 0.
  4. Broadcast: network + block size − 1 in that octet. Octets after it become 255.

For /30 and shorter prefixes, usable hosts = 2(32 − prefix) − 2 (/31 and /32 are special, see below). First host = network + 1, last host = broadcast − 1.

Example 1: 172.16.45.130/26

  • /26 → fourth octet, 26 − 24 = 2 bits → mask 192, block 64.
  • 130 rounded down to a multiple of 64 → 128.
  • Network 172.16.45.128, broadcast 128 + 64 − 1 = 172.16.45.191.
  • Hosts .129 – .190, 26 − 2 = 62 usable.

Example 2: 10.20.77.9/20

  • /20 → third octet, 20 − 16 = 4 bits → mask 240, block 16.
  • 77 rounded down to a multiple of 16 → 64.
  • Network 10.20.64.0, broadcast 10.20.79.255 (64 + 16 − 1 = 79, last octet 255).
  • 212 − 2 = 4,094 usable hosts.

Example 3: the questions interviewers love

"How many /27s fit in a /24?" 2(27 − 24) = 8. Each has a block size of 32.

"I need 50 hosts. Which prefix?" Find the smallest 2n − 2 ≥ 50: 64 − 2 = 62 → 6 host bits → /26.

"I need 500 hosts?" 512 − 2 = 510 → 9 host bits → /23.

"Are 192.168.1.70 and 192.168.1.130 in the same /25?" Block 128: 70 → network .0, 130 → network .128. No.

Edge cases worth knowing

  • /31: two addresses, both usable on point-to-point links (RFC 3021). No broadcast.
  • /32: a single host. You'll see it in host routes, loopbacks and firewall address objects.
  • Wildcard masks (ACLs, OSPF) are just 255 − mask in every octet: /26 → 0.0.0.63.

Practice until it's boring

Speed comes from repetition, not understanding. Once you understand the four steps, do twenty random examples a day for a week. I built a small game for exactly that: Subnet Sprint on my homepage gives you 60 seconds of random questions and remembers your high score. Beat 15 and you're interview-ready.
