The goal

We want a script that takes a log export from FortiGate or FortiAnalyzer and answers three questions:

  1. Who is scanning us? Sources hitting many different ports.
  2. Who is knocking on sensitive doors? Repeated attempts on SSH, RDP, SMB.
  3. What did the IPS consider serious? High and critical signatures.

The output is a single HTML file, sorted by severity. No database, no framework, nothing to install except Python 3.

Step 1: understand the log format

FortiOS logs are key=value pairs, with quotes around values that may contain spaces. Two typical lines (IPs from documentation ranges):

date=2026-09-01 time=10:15:02 devname="FGT-HQ" type="traffic" subtype="forward" level="notice" srcip=203.0.113.45 srcport=51544 dstip=198.51.100.10 dstport=22 proto=6 action="deny" policyid=0 service="SSH"
date=2026-09-01 time=10:16:40 devname="FGT-HQ" type="utm" subtype="ips" level="alert" severity="critical" srcip=203.0.113.77 dstip=198.51.100.20 dstport=443 attack="Apache.Log4j.Error.Log.Remote.Code.Execution" action="dropped"

Export from FortiAnalyzer (Log View → Download) or from the FortiGate log view in raw format.

Step 2: parse it

Python's shlex module already knows how to split a line on spaces while respecting quotes. That makes the parser tiny:

import shlex

def parse_line(line):
    record = {}
    try:
        tokens = shlex.split(line)
    except ValueError:  # truncated line / unbalanced quote: skip it, don't crash the report
        return record
    for token in tokens:
        key, sep, value = token.partition("=")
        if sep:
            record[key] = value
    return record

def load(path):
    with open(path, encoding="utf-8", errors="replace") as fh:
        return [parse_line(line) for line in fh if line.strip()]

Each log line becomes a dictionary like {"srcip": "203.0.113.45", "dstport": "22", "action": "deny", …}.

Step 3: score suspicious behaviour

Keep the rules simple and explainable. A security team trusts a report it understands. Every finding is a tuple of (severity, source, message):

from collections import Counter, defaultdict

SENSITIVE = {"22": "SSH", "23": "Telnet", "445": "SMB", "3389": "RDP"}

def score(records):
    findings = []
    denies = [r for r in records if r.get("action") == "deny"]

    # 1. Port scans: one source, many distinct destination ports
    ports_by_src = defaultdict(set)
    for r in denies:
        ports_by_src[r.get("srcip")].add(r.get("dstport"))
    for src, ports in ports_by_src.items():
        if len(ports) >= 20:
            findings.append(("high", src, f"Port scan: {len(ports)} distinct ports denied"))

    # 2. Repeated attempts on sensitive services
    hits = Counter((r.get("srcip"), r.get("dstport")) for r in denies if r.get("dstport") in SENSITIVE)
    for (src, port), n in hits.items():
        if n >= 10:
            findings.append(("medium", src, f"{n} denied attempts on {SENSITIVE[port]} ({port})"))

    # 3. IPS events the FortiGate itself rated high or critical
    for r in records:
        if r.get("subtype") == "ips" and r.get("severity") in ("high", "critical"):
            findings.append(("high", r.get("srcip"), f"IPS {r.get('severity')}: {r.get('attack')}"))

    return findings
Tune it

The thresholds (20 ports, 10 attempts) are starting points. Run the script on a week of normal logs first and adjust until the report shows things you'd actually act on. A report that cries wolf gets ignored.

Step 4: render the report

An HTML table is enough. The important detail is html.escape: log fields come from the network, which means they come from attackers. Never paste them into HTML unescaped.

from datetime import date
from html import escape

ORDER = {"high": 0, "medium": 1, "low": 2}

def render(findings, path="report.html"):
    rows = "\n".join(
        f"{sev.upper()}{escape(str(src))}{escape(msg)}"
        for sev, src, msg in sorted(findings, key=lambda f: ORDER[f[0]])
    )
    page = f"""
Threat report {date.today()}


Threat report: {date.today()}


{len(findings)} findings


{rows}

SeveritySourceFinding
"""
    with open(path, "w", encoding="utf-8") as fh:
        fh.write(page)

if __name__ == "__main__":
    import sys
    render(score(load(sys.argv[1])))

Run it with python report.py fortigate-export.log and open report.html.

Step 5: automate it

  • Schedule it: Windows Task Scheduler or a cron job every Monday morning, so the report is ready before the meeting.
  • Enrich it: add a reverse-DNS lookup or country information for source IPs.
  • Trend it: save the findings as JSON each week and compare. "Scans up 300% since last week" is a much better conversation starter than a raw list.
Scope

This is a lab-grade tool for learning and small environments. At scale, the same logic belongs in FortiAnalyzer event handlers or a SIEM. Building it yourself first is how you learn what those tools are actually doing.

What you learned

Parsing, aggregating, scoring and safe rendering: the same four steps behind every commercial security dashboard. Once you've built a small one yourself, the big ones stop being magic. You'll know what questions to ask them.
